# Contributing to Govee H5198 Bluetooth Temperature Monitor

Thank you for your interest in contributing to this project! This repository was originally "vibe coded" by Google Gemini 3, and we welcome improvements, bug fixes, and new features from human developers.

## How to Contribute

### 1. Reporting Bugs
- Check the existing issues to see if the bug has already been reported.
- If not, open a new issue with a clear description of the problem, steps to reproduce it, and your environment details (OS, Python version).

### 2. Suggesting Enhancements
- Open an issue to discuss your proposed enhancement.
- Explain the use case and how it benefits the project.

### 3. Pull Requests
- Fork the repository and create your branch from `develop`.
- Ensure your code follows the existing style and conventions.
- Provide a clear and concise description of your changes in the PR.
- All PRs should be targeted at the `develop` branch.

## Code Guidelines
- **Python Style**: Follow PEP 8 where possible, but maintain consistency with the existing codebase.
- **Dependencies**: Keep dependencies to a minimum. Currently, the project relies primarily on `bleak`.
- **Documentation**: Update the `README.md` if your changes introduce new features or change existing usage patterns.

## A Note on AI-Assisted Development
Since this project was built with significant assistance from AI, please be thorough in your code reviews. We value human oversight to ensure robustness and safety.

By contributing, you agree that your contributions will be licensed under the project's existing license.
